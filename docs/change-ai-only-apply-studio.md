# 功能改造说明：AI 单引擎 · 教学应用改造 · 工坊放开知识点

> 适用版本：2026-11-04 之后的工作副本
> 涉及路由：`/apply`（重写）、`/agent`（重构两步）、`/settings`、`/workspace`（文案）
> 一句话：**站点不再有本地引擎；教学应用改为「章节 → 知识点 → 卡内 AI 分析」；工坊的落点只选学科，知识点放开到全书，最后交给 AI 生成。**
>
> ⚠️ 部分内容已被后一轮改造取代：本文提到的工坊「民俗素材」选择区已整体移除，资源库也改为

## 一、移除本地引擎，只保留 AI

### 1.1 变更点

| 层面 | 改前 | 改后 |
| --- | --- | --- |
| 生成路径 | 规则拼装（本地）+ AI 增强，AI 失败自动回退本地 | **只有 AI**。没有本地分支，没有回退 |
| 生成入口 | `generatePlan()`（`lib/agent/engine.ts`）+ `generateWithLLM()` | `generatePlanWithAI()`（`lib/agent/llm.ts`） |
| 方案结构 | `GeneratedPlan.engine: 'local' \| 'llm'` | 删除 `engine` 字段；`EngineKind` 类型一并删除 |
| 结果兜底 | AI 失败 → 返回本地方案 + note 说明 | AI 失败 → 抛 `AiError`，界面显示原因与重试 |
| 模板库 | `templates.ts` 含环节模板、准备清单、失误表 | 只保留提示词要用的 `VERBS` / `CATEGORY_VOICE` / `SUBJECT_VOICE`（11.6 KB → 4.5 KB） |
| 构建门禁 | `check:paths`（断言三条生成路径） | 删除。引擎不存在，路径断言随之失效 |

**删除的文件**

- `src/lib/agent/engine.ts` —— 规则拼装引擎（458 行）
- `scripts/check-paths.ts`、`scripts/run-paths.mjs` —— 三路径运行时校验
- `templates.ts` 中的 `STAGE_SETS`、`StageTemplate`、`PREP_BASE`、`COMMON_ERRORS`、`CARD_VOICE`

**保留的文件及理由**

- `lib/agent/prompt.ts`：提示词是现在唯一的质量来源，必须保留并继续维护
- `lib/agent/fusionRules.ts`：提供章节视角与融合角度，仍是提示词素材
- `lib/agent/templates.ts`（裁剪后）：只留「写给模型看的口径」，不再参与拼装

### 1.2 相关入口、状态与依赖的处理

| 位置 | 改前文案/行为 | 改后 |
| --- | --- | --- |
| 工坊页头徽标 | 「AI 增强已启用 / 本地组装引擎」 | 「AI 已就绪 / AI 未配置」 |
| 工坊第 3 步按钮下方 | 「将调用 AI 增强生成，失败自动回退本地引擎」/「使用本地组装引擎，不需要网络」 | 「提交后由 AI 生成，通常 20–60 秒；失败会给出原因，不代写方案」/「需要先配置 AI，本站不再提供本地生成」 |
| 结果卡徽标 | 「AI 增强生成 / 本地引擎生成」二选一 | 固定「AI 生成」 |
| 我的空间 · 方案卡 | `AI` / `本地` 双色 Tag | 固定 `AI` |
| 导出 Word 信息表 | `engineLabel` 随引擎变化 | 固定「AI 生成」 |
| 导出 Markdown 头部 | 「生成引擎：AI 增强 / 本地组装引擎」 | 「生成方式：AI 辅助生成」 |
| 设置页 | 「AI 增强是可选项。不配置也能用本地引擎」 | 「AI 是唯一生成引擎；不配置则无法生成与分析」 |
| 设置页回退说明 | 「失败自动回退到本地组装引擎」 | 「直接给出原因并保留重试，不用模板拼一份方案」 |
| 设置页标签 | 「双引擎备课」 | 「AI 生成」 |
| 学情预设维护说明 | 「界面、本地引擎、AI 提示词会自动跟上」 | 「界面、AI 提示词会自动跟上」 |
| `package.json` | `build` 内含 `run-paths.mjs`；`check:paths` 脚本 | `build = tsc --noEmit && verify && vite build`；删除 `check:paths` |

**状态处理（四类失败各有出口，不用同一句「生成失败」糊过去）**

| 失败类型 | 判定 | 界面表现 |
| --- | --- | --- |
| 未配置 | 开关关闭 / 缺 Base URL / 缺 Key | 点击生成后出现内联提示「尚未配置 AI 服务」+「去设置」链接；条件不丢 |
| 鉴权失败 | 401 / 403 | 提示 Key 无效，允许直接重试（改 Key 需去设置） |
| 网络 / 超时 | fetch 失败、90 秒无响应、429 | 提示具体原因（超时多少秒 / 状态码），可重试 |
| 返回格式不符 | 非 JSON、目标为空、流程不足 3 环节 | 提示重试或换模型；**不生成半成品方案** |
| 字段缺失 | 评价、重点、准备等漏写 | 空串留白 + `note` 说明「AI 未填写…已在方案中留空，可点编辑补齐」 |

**依赖变化**

- 无新增依赖。`fetch` + `AbortController` 是浏览器原生能力。
- `docx` 动态 import 与导出链路不受影响，仅 `engineLabel` 变成常量。
- 旧本地存储里的方案快照可能仍带 `engine` 字段，读取时被忽略（`normalizePlans` 不校验未知字段）。

### 1.3 交互流程（改后）

```
[设置] 填 Base URL / API Key / 模型 → 测试连接 → 保存
   │
   ├─ 未配置 ──→ 工坊顶部显示「AI 未配置」；点生成 → 内联提示 + 「去设置」
   │
   └─ 已配置 ──→ 工坊第 3 步点「生成教学方案」
                    ├─ 进度条滚动（整理课程要点 → 调用 AI 生成 → 校验课时配比 → 排版输出）
                    ├─ 成功 → 第 4 步：方案 + 「为什么这样配」三段 + 编辑 / 换一个 / 导出
                    └─ 失败 → 停在第 3 步，条件保留，显示原因 + 重试
```

**为什么取消兜底**：兜底产出的是「看起来完整、实际是模板拼装」的方案，教师无从分辨，会把模板判断当成 AI 判断。宁可失败并说明原因。

## 二、教学应用模块：章节知识点 + 卡内 AI 分析

### 2.1 页面结构变了

改前：10 张学科卡 → 展开看「这门课能承接哪些知识点」。
改后：**先章节、后知识点**，一张卡一个知识点；学科变成筛选条件与分析的定向条件。

```
/apply
├─ 页头：课程里的知识点，怎么进你的课堂
├─ 说明卡
│   ├─ 左：这一页怎么用（① 找知识点 ② 看已有落点 ③ 点 AI 分析）+ 规模数字
│   └─ 右：「我的课堂」= 我教的学科（10 门 + 不限）+ 任教学段（1-2 / 3-4 / 5-6）
├─ 筛选：搜索框（标题 / 摘要 / 章名 / 落点说明）+ 章节 chip（全部 + 01–10）
├─ 列表：按章节分组，每组「序号 章名 · N 个知识点」+ 章简介
│   └─ 知识点卡 ×N
└─ 页尾：《人类与社会》课程出处卡（知识卡 / 民俗 / 素材 / 课例计数）
```

**知识点卡的信息层级**

```
┌───────────────────────────────────────────────┐
│ 01 · 人类的产生与发展 / 人类的家园      [AI 分析] │  ← 章 · 单元 / 触发按钮
│ 宇宙、太阳与地球的形成                          │  ← 标题
│ 了解宇宙起源的主要假说…                        │  ← 摘要
│ 已登记落点  数学·情境导入  科学·素材案例  知识卡 │  ← 事实层（不依赖 AI）
│ ▌语文：为「…」提供…                            │  ← 若已选学科，补一句 why
└───────────────────────────────────────────────┘
```

### 2.2 AI 分析的触发方式

| 项 | 规则 |
| --- | --- |
| 触发点 | 卡片右上角「AI 分析」按钮，**唯一入口**。没有悬浮预览、没有自动加载 |
| 首次点击 | 立刻展开面板 + 发起请求；按钮变「收起」 |
| 点学科 chip | **只改分析对象，不发请求**（2026-11-05 调整）。该学科有缓存则直接显示上次结果，没有则显示「待分析」占位 +「开始分析」 |
| 二次点击 | 已收起且已有结果 → 直接展开，**不重复请求** |
| 收起 | 点「收起」（右上角或错误块里），或再点一次按钮；结果保留在内存 |
| 重新分析 | 结果头部右侧「重新分析」；仅在 `done` 状态出现 |
| 多卡并存 | 每张卡独立展开，互不影响（便于横向比较）；不做手风琴 |
| 缓存键 | `pointId \| subject`，一科一份；切学科不清缓存，切回来直接复用 |
| 缓存失效 | 仅切换「任教学段」整表清空（旧结果对应的是另一间课堂）。「我教的学科」只改卡片默认对象，不清缓存 |
| 并发 | 同一知识点在飞时重复点击被忽略（`inflight` Set），不产生重复请求 |

### 2.3 展开后的内容结构

```
AI 分析 · 怎么用到你的课堂        [面向 语文]        [重新分析]
├─ ① 一句话定位        core：这个知识点在课堂里是什么（≤60 字）
├─ ② 能落到哪些课堂    每条：学科 Tag + 教学内容（点名单元/课题）+ 作用 + 一句怎么用（最多 3 条）
├─ ③ 三步落地          编号 1/2/3：环节名 + 教师做什么、学生做什么
├─ ④ 容易上歪的地方    赭色块，最多 3 条（针对这个点，不是通用课堂管理）
├─ ⑤ 留给学生的追问    一句开放问题
└─ 底栏               「带它去备课」→ /agent?point=…&subject=…  + 生成时间
```

**加载态**：骨架屏 + 轮播文案（读取知识卡 → 对齐已登记落点 → 写课堂用法）+「通常 5–15 秒」。
**错误态**：分两种——`config`（未配置）给「去设置接入」；其他给「重试」。都可以就地收起。
**缺失段**：`classrooms` / `flow` / `cautions` / `ask` 任一为空则不渲染该段，不出现空标题。

### 2.4 交互流程

```
进入 /apply
   │
   ├─ 选「我教的学科」→ 列表收敛为本科已登记落点的知识点（例：语文 31 个）
   │     └─ 再选学段 → 清空分析缓存，后续分析按「语文 · 3-4 年级」写
   ├─ 选章节 → 只看该章（章节 chip 上带数量）
   ├─ 搜索 → 命中标题 / 摘要 / 章名 / 落点说明
   │
   └─ 点某卡「AI 分析」
         ├─ 未配置 AI → 卡内展开错误块（去设置 / 收起），不发请求
         ├─ 请求中   → 骨架屏；其他卡不受影响
         ├─ 成功     → 五段结果 + 「带它去备课」
         └─ 失败     → 卡内显示原因 + 重试（条件不变）
```

## 三、智能备课工坊：定落点只选学科，知识点不限章节

### 3.1 四步语义调整

| 步骤 | 改前 | 改后 |
| --- | --- | --- |
| ① 定落点 | 选学科，且暗示「下一步只列这门课接得住的」 | **只选学科**。文案明确：不限制下一步范围 |
| ② 选知识点 | 只列该学科已登记的落点（0 条时整块空态） | **全书 10 章 73 个任选**；按章节分组、可搜索、可「只看本科已有落点」 |
| ③ 定课程与学情 | 主题必填 + 年级 / 课时 / 风格 / 学情 | 不变 |
| ④ 生成方案 | 本地或 AI 二选一 | **只有 AI**，失败不降级 |

### 3.2 第 2 步的具体规则

- **范围**：全部 73 个知识点，跨章节。学科**不再过滤列表**，只做两件事：
  ① 给已登记的落点打「本科 · 情境导入」这类标签；
  ② 提供「只看本科已有落点（N）」开关（默认关）。
- **分组**：按章节分组，组头「01 人类的产生与发展 · 一句话简介 · 数量」。
- **搜索**：标题 / 摘要 / 单元 / 章名 / 落点说明。
- **上限**：最多 3 个（原有约束不变），第 4 个给 toast 提示。
- **联动**：知识点变化会重算右侧「民俗素材」「教学素材」，来源改为**全书范围内**与该点相关的条目（改前只从所选学科的材料里找，跨章选点会空）。
- **跳过**：顶部常驻「跳过，直接定课程」；不选任何知识点仍可生成，方案按学科主线写。

### 3.3 第 3 步 → AI 生成

```
选好学科 → 选好知识点（0–3 个）→ 填主题（必填）+ 年级 / 课时 / 风格 / 学情
   │
   └─ 点「生成教学方案」
         ├─ 未配置 AI → 内联提示 + 「去设置」，不出方案
         ├─ 成功 → 第 4 步：标题 = 你填的主题（不改写）+ 五环节（分钟合计 = 课时）
         │           + 「为什么这样配」三段 + 编辑 / 换一个 / 存草稿 / 收藏 / 导出 Word
         └─ 失败 → 停在本步，条件保留，显示原因，可重试
```

**「换一个方案」**：同一输入再调用一次，`variant` 递增并在提示词里追加「换一个切入角度与活动组合，课时、主题与所选知识点不得改动」，温度从 0.7 升到 0.95。不再通过本地变体号换模板。

## 五、已知限制

1. **分析结果只在内存**：刷新即失，也不进「我的空间」。若需要留存，下一步是把 `PointAnalysis` 落 localStorage 并在卡片上标「上次分析于 …」。
2. **缓存粒度是知识点 × 学科**：一科一份结果，切学科不清缓存；只有切学段才整表作废。切到没分析过的学科时不会自动跑，需再点「开始分析」——避免挑学科这一动作顺手烧掉一次调用。
3. **多卡并发可能触发限流**：只对同一点去重，不同点可同时请求；接 429 时会在卡内提示，不影响其他卡。
4. **旧快照的 `engine` 字段**：仍存在本地存储里，但不再读取，也不影响导出（导出统一写「AI 生成」）。
5. **`prompt.ts` 现在是唯一质量来源**：以后改口径等于改全站方案写法，建议改动后在真实模型上跑一次「不借知识点」和「借 3 个跨章知识点」两种输入。
